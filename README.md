# Portfolio Website

This is a personal portfolio website designed to showcase my projects, skills, and experience. Built using React, this single-page application (SPA) offers a modern and interactive experience to visitors.

## Project Overview

- **Live Link**: [Visit the Portfolio](https://xxender13.github.io/harshilreact/#/)
- **Technologies Used**: React, CSS, JavaScript

## Features

- **About Me**: Brief overview of my background, skills, and interests.
- **Projects**: Displays a selection of my top projects with descriptions, images, and links to further details or repositories.
- **Resume**: Provides a downloadable PDF of my resume.
- **Contact Form**: Allows visitors to reach out to me directly through the website.

## Project Structure

The project files are structured as follows:

- **index.html**: Main HTML file that serves as the entry point for the React app.
- **manifest.json**: Configuration file for PWA compatibility.
- **favicon.ico**: Custom favicon for the website.
- **resume.pdf**: Downloadable resume file.
- **static/css**: Contains the CSS stylesheets, including:
  - `main.css`: Main stylesheet for layout, colors, typography, and responsive design.

- **static/js**: Contains JavaScript files, including:
  - `main.js`: The primary JavaScript file that controls React functionality and page rendering.

- **static/media**: Directory containing all media assets used in the portfolio, such as:
  - **Images**: Project preview images, icons, and additional graphics for the UI.

### Key Components

- **Reusable Components**: Modular components in React such as:
  - **Navbar**: Navigation bar for easy access to different sections.
  - **Hero Section**: Introduction section with a hero image.
  - **Project Cards**: Displays project previews with interactive elements.
  - **Contact Form**: Validates input and sends messages directly to my email.

## CSS Styles

- **Flexbox Layouts**: Used extensively for layout and positioning.
- **Responsive Design**: Media queries are included to ensure the site is mobile-friendly and scales well on all screen sizes.
- **Branding**: Consistent use of colors, fonts, and button styles for a cohesive visual identity.

## JavaScript Functionality

- **React Router**: Enables smooth transitions between sections without reloading.
- **Dynamic Data**: Populates project details dynamically, making it easy to add or update projects in the future.
- **Event Handlers**: JavaScript functions handle form submission, input validation, and interactions within the project sections.
